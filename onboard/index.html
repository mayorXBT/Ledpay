Ledpay · Ledger-owned Kernel session

Authorize a scoped spending key

This page runs in desktop Chromium because Ledger WebHID cannot run inside the hosted PayBox plugin sandbox. The Ledger private key never leaves the device. The session key is created by the executor and can only transfer the named test token to the named recipient, under the per-call cap, until expiry.

  1. Quit Ledger Live. USB HID is exclusive, so Live will make Chrome look frozen.
  2. Unlock Ledger Flex and open the Ethereum app. Unlocked on the dashboard is not enough.
  3. Click Connect. The first time, Chrome opens a device picker at the top of this tab. After that it reuses the granted Flex.
  4. Confirm the address on the Flex screen, then authorize the session.
  5. Fund the Kernel address with test ETH and the test token. Do not send funds to the Ledger EOA for agent spend.

Ledger Agent Intent is a per-transaction approval product. Ledpay does not use it for autonomous spend. Autonomous spend uses a ZeroDev Kernel permission that you authorize once on the Ledger.
