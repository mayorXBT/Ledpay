Ledpay · Ledger-owned Kernel session

Authorize a scoped spending key

Runs in Chromium (desktop or Android Chrome). Ledger WebHID / Web Bluetooth cannot run inside the hosted PayBox plugin sandbox. The Ledger private key never leaves the device. The session key is created by the executor and can only call USDC transfer under the per-call cap until expiry — to any address.

  1. Quit Ledger Live (USB HID is exclusive; Live will block Chrome).
  2. Unlock the Ledger and open the Ethereum app.
  3. Connect with USB (desktop WebHID) or Bluetooth (Chrome on Android or desktop). Chrome opens the device picker at the top of the tab / system sheet.
  4. Confirm the address on the Ledger screen, then authorize the session.
  5. Fund the Kernel address with test ETH and USDC. Do not send agent funds to the Ledger EOA.

Bluetooth needs Chrome + HTTPS (or localhost). iOS Safari does not support Web Bluetooth. Ledger Agent Intent is a per-transaction approval product; Ledpay uses a one-time Kernel permission instead.
